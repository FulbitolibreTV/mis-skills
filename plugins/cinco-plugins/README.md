# Cinco plugins para Claude Code

Este es un **asistente de instalación y comprobación** de cinco herramientas externas: Playwright, OmniRoute, Headroom, MemPalace y Frontend Design.

No incorpora ni instala automáticamente el código de terceros. Se usa como skill de Claude Code para explicar los pasos, pedir permiso y comprobar qué quedó configurado.

## Usar

1. En Claude Code, registra el marketplace de `FulbitolibreTV/mis-skills`.
2. Instala el plugin `cinco-plugins`.
3. Invoca `/cinco-plugins:instalar-cinco-plugins` o busca esa skill en `/skills`.

También acepta `comprobar`, `deshacer` y la selección `1,3` como argumentos. Lee `GUIA.md` antes de instalar programas de terceros.

**Este kit es independiente de `becario-kit`**: el kit original incluye MODS, mientras que este usa OmniRoute como quinto componente del conjunto de la guía.
