# 1 · Preparar el editor (una sola vez)

En la app de escritorio de Claude → pestaña **Code** → entorno **Local** → elige la carpeta donde quieras el editor (por ejemplo, Documentos). Copia y pega:

```
Usa la skill becario-editor y prepárame el editor de vídeo en esta carpeta.
Comprueba qué herramientas me faltan (HyperFrames o Remotion, FFmpeg y Whisper),
dime qué vas a instalar y, cuando te dé permiso, instálalo tú.
Después crea la carpeta Editor IA y haz la prueba corta para ver que todo funciona.
```

Cuando acabe, abre una sesión nueva con la carpeta **Editor IA** seleccionada: a partir de ahí, Claude ya sabe editar en ella.

¿Quieres Remotion en vez de HyperFrames? Añade al final: «Usa Remotion como motor».
